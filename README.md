# La aguja en el pajar

Juego 3D para móvil: encuentra una aguja escondida entre 5.000.000 de briznas de heno.

**Jugar:** https://plasenciahandball.github.io/la-aguja-en-el-pajar/

- Joystick a la izquierda para andar, arrastra a la derecha para mirar y mantén **Coger** frente a la paja.
- Vende la paja en el puesto de fuera del granero y compra herramientas, carretillas, camiones, cinta transportadora y ayudantes.
- Modo normal y modo purista (sin ayudas).
- En ordenador: WASD, ratón y barra espaciadora.

Necesita internet al abrirlo (carga el motor 3D y las fuentes). La partida se guarda en el navegador de cada persona.
